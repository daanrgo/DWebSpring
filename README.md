# Portico

El portico es una implementación desarrollada en Java Spring, HTML, CSS y Docker. Esta es la implementación para un restaurante de venta de hamburguesa el cuál cuenta con 3 usuarios principales:
1. Clientes.
2. Operadores.
3. Administrador (root).

Cada uno de estos usuarios cuenta con sus propias pantallas para poder poder crearlos, actualizarlos, verlos y eliminarlos.
